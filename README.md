# 从 Java 到移动端 · 交互式学习软件

一个可以在电脑和手机上打开的学习软件：从 0 开始学 Java，再一路走到 Android 移动开发。
课程内容、随堂测验、编程练习、实战项目、进度记录都在这一个页面里。

## 怎么打开

**Windows（推荐）**

双击 `启动学习软件.bat`。脚本会启动一个本地服务器并自动打开浏览器（需要电脑已安装 Node.js，没有装也能运行，只是进度保存可能不可用）。

**其他系统 / 手动方式**

- 直接双击 `index.html`（最简单的办法，Chrome / Edge / Safari 都能打开）
- 或在当前目录执行下面任意一条命令，然后访问 http://localhost:8765/

```bash
node -e "console.log('见 启动学习软件.bat 里的完整命令')"
# 有 Python 的话更简单：
python -m http.server 8765
```

**在手机上使用**

最省事的办法就是「同一个 WiFi + 局域网地址」：

1. 在电脑上双击 `启动学习软件.bat`，命令行窗口里会打印一行 `Open on your phone`，那就是手机要输入的地址（形如 `http://192.168.x.x:8765/`）。
2. 手机连上**和电脑同一个 WiFi**，用手机浏览器打开这个地址即可。
3. 不想记 IP？在软件里点右上角的 **📱 按钮**（或「我的进度 → 📱 在手机上学习」），会直接显示地址和复制按钮；也可以让电脑浏览器打开 http://localhost:8765/phone 看同样的说明页。

用手机访问时要注意：

- 电脑上那个命令行窗口要**一直开着**，关掉手机就访问不了了。
- 第一次运行时 Windows 会弹防火墙提示，要选「允许访问」。
- 学习进度存在「当前浏览器」里，**电脑和手机的进度各自独立**，不会自动同步；想带着进度走，用「我的进度 → 导出进度 / 导入进度」搬运那串 JSON。
- 手机屏幕小，写长代码不方便：建议在电脑上写代码、跑程序，用手机看讲解、做测验、复习速查手册，这些在手机上体验很好。

打不开时的排查顺序：电脑服务器窗口还开着吗 → 手机和电脑是不是同一个 WiFi（别用流量）→ 防火墙是否允许了 node.exe → 公司/学校 WiFi 常禁止设备互访，可以打开手机热点让电脑连上再试 → 路由器重启后 IP 会变，重新点 📱 按钮看新地址。

另一个方案：把整个 `java-mobile-learn` 文件夹传到手机，用手机浏览器直接打开 `index.html`（不用服务器，但进度可能无法保存，而且示例运行依赖的本地存储同样受限）。

## 想让电脑关机后也能访问？（把网站发布到公网）

**能做，而且这个项目很适合**：整个软件是**纯静态**的——没有后端、没有数据库、不依赖任何外部 CDN，换句话说，这个文件夹本身就是完整的网站，放到任何静态托管上都能直接跑。

要做到「电脑关机也能访问」，本质是**换一台一直开着的机器来提供服务**。免费托管就是干这个的，下面三种都不需要写代码、不需要装环境：

| 方式 | 大概耗时 | 得到的网址 | 说明 |
| --- | --- | --- | --- |
| **Netlify Drop** | 1 分钟 | `https://xxx.netlify.app` | 打开 `app.netlify.com/drop`，把 `java-mobile-learn-deploy.zip`（在上级 `outputs` 文件夹里，或直接用整个 `java-mobile-learn` 文件夹）拖进去就上线。不登录可临时用，登录后可长期保留。 |
| **Cloudflare Pages** | 5 分钟 | `https://xxx.pages.dev` | 进入 `dash.cloudflare.com` → Workers & Pages → Create → Pages → Upload assets，上传 zip 即可。国内访问相对稳定。 |
| **GitHub Pages** | 10 分钟 | `https://用户名.github.io/仓库名/` | 新建仓库 → 上传 `index.html`、`assets/`、`content/`（保持目录结构）→ Settings → Pages → Source 选 `main` / `(root)`。国内访问有时偏慢。 |

已经有一台常开的服务器 / NAS / 小主机的话，把文件夹拷过去，用 nginx 或者 `python -m http.server 80` 起个静态服务也一样，效果相同。

**发布之后要注意两件事：**

1. 学习进度保存在**每台设备各自的浏览器**里，所以电脑、手机、平板的进度互相独立，不会自动同步；想搬进度就用「我的进度 → 导出进度 / 导入进度」复制那串 JSON。
2. 线上打开时，右上角 📱 按钮会自动认出「这已经是线上网址」，直接给你可分享的完整链接（含子路径），不会再提示局域网那套步骤。

### 一步一步：用 GitHub Pages 发布（纯网页操作，不用命令行）

前置：有一个 GitHub 账号（github.com 免费注册）。免费账号的 Pages 只能用于**公开仓库**（也就是内容公开可见）。

1. 打开 https://github.com/new
   - **Repository name** 填 `java-mobile-learn`
   - 选 **Public**；**不要**勾 "Add a README file"
   - 点 **Create repository**
2. 在新建好的空仓库页面点 **uploading an existing file**（也可以点 **Add file → Upload files**）
3. 把 `java-mobile-learn` 文件夹里的这些东西**一起拖进去**（拖文件夹进去 GitHub 会自动保留目录结构）：
   - `index.html`
   - `assets` 文件夹、`content` 文件夹
   - `README.md`、`.nojekyll`、`server.js`、`启动学习软件.bat`（这几个可有可无）
   - 注意：**不要上传那个 zip 压缩包**，GitHub 不会帮你解压；要拖解压后的文件和文件夹。
4. 等文件全部上传完，在下方 Commit changes 里随便写一句话，点 **Commit changes**
5. 打开仓库的 **Settings → Pages**
6. Source 选 **Deploy from a branch**；Branch 选 **main**，右边目录选 **/ (root)**，点 **Save**

8. 把这个网址发到手机、或发给别人即可 —— 它跑在 GitHub 的服务器上，和你自己的电脑开没开机没关系。

以后想更新内容，重复第 2～4 步（把改动过的文件重新上传）就行，Pages 会自动重新构建。

## 学习建议

1. 按 `01 → 20` 的顺序学，前一章是后一章的基础。
2. 每章流程：看讲解 → 做测验 → 写练习 → 打卡。练习一定要自己敲，卡住了先看提示。
3. Java 部分学完 7 章就可以做「项目 1、项目 2」，学完 13 章做「项目 3、项目 4」，第 14~16 章的 IO / 集合 / 多线程是面试重点，建议配合项目 4 一起练。
4. Android 部分（第 17~23 章）学完「数据存储」做「项目 5」，学完「网络请求」做「项目 6」，这个项目可以直接写进简历。
5. 每天 1～2 小时，Java 阶段约 6～8 周，Android 阶段约 6～8 周。

**关于多线程示例的特殊说明**：浏览器是单线程环境，运行器把线程模拟成“按创建顺序依次执行完”，所以输出是确定性的、看不到真实的交错与抢锁；竞态条件（丢更新）和 wait/notify 这两个例子特意标为“请在 IDEA 里运行”，这样才能看到真实行为。每个相关示例下方都写明了这一点。

**知识点讲解里的示例代码** 和 **每道练习** 都能直接运行：

- 讲解里的示例：代码块右上角有 **▶ 运行**，点一下就能看到这段代码的真实输出。片段代码（只有几行语句）会自动包裹成可运行的程序；依赖其他类的示例（例如测试类用到 `Student`）会自动把依赖的类一起带上。
- 练习区：写完点 **▶ 运行代码**，页面下方会显示程序真实的 `System.out` 输出，并自动和“期望输出”对比。

- **跑一遍参考答案**：想先看看正确结果长什么样，点这个按钮即可，不会覆盖你自己的代码。
- **Scanner 输入**：需要键盘输入的程序（例如 BMI 计算器）会出现一个输入框，按行填写输入数据再运行。
- **支持范围**：这是为教学写的一个轻量运行器，覆盖常用语法——变量与类型（含 `var`）、数组、分支循环、`switch` 语句与 `switch` 表达式、方法重载/递归/可变参数、类/继承/接口/多态、`super` 与 `this(...)`、**多文件（一次编译多个 .java 文件）**、异常处理（含多重 catch 与 `getMessage()`）、字符串与 `StringBuilder`、ArrayList/HashMap/HashSet 与 lambda、Scanner、文件读写模拟、日期时间、`instanceof` 模式匹配等。课程里的 82 段可运行示例和 30 道 Java 练习都已逐一验证可运行（包含带依赖文件的多文件示例）。
- **死循环保护**：示例里如果写出永远结束不了的循环，运行器会在几毫秒内中止并提示，不会把浏览器卡死。
- **不支持的部分**：多线程、网络、GUI、完整的 Java 标准库。遇到提示“暂不支持/找不到标识符”，把代码复制到 IDEA 里运行即可。
- **Android 章节**：Android 代码需要 SDK 和模拟器，无法在浏览器里运行，所以这些练习只提供关键点检查，请在 Android Studio 中运行验证。

### 多文件与「我的类库」（跨文件调用别的类）

真实项目不会把所有代码写进一个文件，软件内部也支持这一套：

- **练习自带的依赖文件**：有些练习（例如 9-3、15-3）会额外给你一个独立的辅助类文件，比如 `MathBox.java`、`Student.java`。它会出现在练习区的「🧩 依赖文件」面板里，点开就能看代码；运行时会和你的代码一起编译，你只要写 `MathBox.max3(3, 9, 5)`、`new Student("小明", 96)` 就能调用它。
- **我的类库**：左侧目录里的「🧩 我的类库」可以新建自己的 `.java` 文件。文件名必须和 `public` 类名一致（例如 `Calculator.java` 里写 `public class Calculator`）。保存之后，**所有**讲解示例和练习的运行都会自动带上这些文件，于是你在任意练习里写 `Calculator.add(1, 2)` 都能直接跑起来。
- **自动 / 手动开关**：类库默认在所有运行中自动附带；在类库页面或练习区的依赖面板里可以随时关掉。
- **出错会指路**：类库文件如果有语法错误，练习区面板和类库页面会标出是哪个文件、错在哪里——因为一个文件出错会让所有运行都失败。
- **同名冲突**：如果练习自带的辅助文件和你的类库文件重名，以练习自带的为准。
- **入口优先**：即使依赖文件里写了 `main`，程序入口仍然优先用你当前正在写的这段代码。

> 想在 IDEA 里练同一套代码？把两个文件分别建成 `Calculator.java` 和 `Main.java`，放在同一个包下，源码可以原样复制过去。
## 关于“关键点检查”的说明

练习题里的“检查关键点”是在浏览器里用规则匹配你的代码（例如是否写了 `class`、`main` 方法、`for` 循环等），**不是真正编译运行 Java**。
它用来帮你发现“明显漏掉的步骤”，配合上面的“运行代码”一起用效果最好：先看运行结果是否正常，再看关键点是否齐全。

## 想自己加内容？

1. 打开 `content/` 下任意一个课程文件，照着里面的结构复制一章，改 `id`（必须唯一，例如 `j14`）和 `title`。
2. 保存后刷新浏览器，左侧目录会自动出现新章节。
3. 需要新增一套课程模块时，在 `assets/app.js` 顶部的 `MODULES` 数组里加一项，并把新文件在 `index.html` 里用 `<script>` 引入。
4. 想让某道练习自带“多文件”的辅助类，在练习对象里加一个 `files` 字段即可：

   ```js
   files: [{ name: 'MathBox.java', code: 'public class MathBox { ... }' }]
   ```

   文件名要和里面的 `public` 类名一致；运行时会自动和学员的代码一起编译。

## 常见问题

**进度没有保存？**
直接双击 `index.html` 打开时，部分浏览器会限制本地存储。用 `启动学习软件.bat` 通过本地服务器打开即可正常保存。

**运行时报“找不到类 XXX”？**
先检查三件事：① 被调用的类所在文件名和类名是否一致；② 「我的类库」的自动附带开关是不是被关掉了；③ 如果类在别的包里，是否忘了 `import`。在软件里把工具类放进「我的类库」，就等于把它放进同一个包，写 `类名.方法名(...)` 就能调用。

**练习检查没通过，但我确定代码是对的？**
“关键点检查”只看结构特征。如果你的写法结构和参考答案差别很大（例如把逻辑拆成了别的方法），可能命中不了关键点，此时可以点“标记完成”做自我评估。

**手机上看代码不方便？**
建议手机上用横屏看代码块，或者主要在电脑上写代码、用手机做测验和复习。

这台电脑上已经装好了 Java 与 Android 开发环境（免管理员权限，全部放在 `C:\Users\zaish\Documents\Codex\AndroidDev`）：

| 组件 | 版本 / 路径 |
| --- | --- |
| JDK | 17.0.2 → `AndroidDev\jdk-17.0.2` |
| Android SDK | platform-tools、platforms;android-35/36、build-tools;35.0.0/36.0.0 → `AndroidDev\Android\Sdk` |
| Android Studio | 2025.1.2 → `AndroidDev\android-studio`（用 `打开AndroidStudio.bat` 启动） |

用 `检查环境.bat` 自检，需要模拟器时运行 `安装安卓模拟器.bat`。详细说明见 `环境说明.md`。
